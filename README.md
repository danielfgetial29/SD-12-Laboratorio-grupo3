# SD-12: Laboratorio: Evaluación de Fin de Módulo

## Descripción

Desarrollo de una aplicación en JavaScript que permite interactuar con una API REST para gestionar registros de usuarios, utilizando Fetch API y JSON Server como servidor local.

## Tecnologías

- JavaScript
- Node.js
- Fetch API
- JSON Server (^0.17.4)
- Git y GitHub
- Python / pytest (pruebas proporcionadas)
